# Overview
This project allows the user to become a painter without the fear of making mistakes or
damaging their real environment with paint. It was realized during a semester at the FIB in Spain.  
This application is an Augmented Reality project developed for the Meta Quest 3 headset.
When launching the application, passthrough will allow the user to see the real environment
and canvas will appear. You then will be able to paint on it.  
The user can interact with several objects and modify different settings through direct hand
interactions with virtual elements.

# Technical details
The project has been developed using Unity 2022.3.62f2 and the MetaXR All-in-One SDK.  
Here is a link to the github repository: [Astri2/FIB-VAR-AR-Project](github.com/Astri2/FIB-VAR-AR-Project). You can clone it.  
Here is a link to the apk download: [Releases · Astri2/FIB-VAR-AR-Project](https://github.com/Astri2/FIB-VAR-AR-Project/releases). It has been tested
on the Meta Quest 3 headset.
